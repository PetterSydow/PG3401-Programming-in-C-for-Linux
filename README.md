# PG3401 – Programming in C for Linux

Eksamensbesvarelse i **PG3401 Programming in C for Linux** ved Høyskolen Kristiania, våren 2026.

**Karakter: A**

## Innhold

Eksamen besto av flere oppgaver i C med fokus på blant annet:

- ANSI C / C89
- Makefiles
- Pekere og dynamisk minnehåndtering
- Datastrukturer og dobbeltlenkede lister
- Threads og mutexes
- XTEA-relatert arbeid
- Socket-programmering
- Protokollhåndtering
- Debugging og Valgrind

## Oppgaver

### Task 2
Tilpasning av eksisterende kode til C89, oppdeling i flere kilde- og headerfiler og bruk av dynamisk minne.

### Task 3
Program for håndtering og vurdering av eksamenskandidater, bygget rundt en dobbeltlenket liste og separat logikk for input, meny og vurdering.

### Task 4
Arbeid med threads og mutexes, samt videre arbeid med XTEA-relatert funksjonalitet.

### Task 5
TCP-server med socket-oppsett, enkel protokollhåndtering og mottak av filer.

### Task 6
Nettverksklient med pakkehåndtering, ACK/NACK, checksum-kontroll og sortering av pakker etter sekvensnummer før skriving av mottatt fil.
